第 1 步 · 环境准备

风险告知

先看清会发生什么，再决定是否继续。小光不是网易官方产品。

第三方程序、直连网易服务器、账号可能被封（我们的号曾被判“使用外挂、脚本”封禁）、不得使用主号。

  • 不是网易官方产品，按游戏协议直接连接网易服务器；使用它违反游戏用户协议。
  • 不得使用主号：只用一个单独的、丢了也不心疼的账号。
  • 游戏名称与地形由本机生成；账号登录与自动续期通过你配置的私有服务完成，本机不保存邮箱密码。
  • 密码摘要与续期凭据由私有服务加密托管；设备由私有服务在登录时登记。

第 2 步 · 环境准备

检查 MuMu

小光要在 MuMu 模拟器里读游戏画面和内存来录图。

需要：MuMu 12、打开「手机 Root 权限」并重启模拟器、在 MuMu 里装好光遇并登进遇境。

  1. MuMu 设置 → 其他设置 → 打开「手机 Root 权限」，然后重启模拟器。
  2. MuMu 里装好光遇 0.16.7 / 421589，登录要给小光用的号，走进遇境。
  3. 如果杀毒软件拦 adb，把 MuMu 目录加进信任。
第 3 步 · 环境准备

游戏安装包

要用你自己从 MuMu 里拉出来的安装包生成游戏数据；小光只适配 0.16.7 / 421589，版本不对会明确说明。

或

安装包放在 data\game\0.16.7-421589\apk\；native 库会从安装包里取出来放到 data\runtime\native\，不会随小光安装包分发。
