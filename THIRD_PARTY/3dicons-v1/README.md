# 3dicons V1 assets

The desktop UI uses three white clay PNGs by Vijay Verma / realvjy: Star,
Chat Bubble and Map Pin. Their unmodified PNG bytes are embedded as data URLs
in the `cloudIcon` function in `app/web/desktop.js`; no runtime CDN request or
separate PNG file is needed. Star decorates the service-account page heading; the other two
illustrations decorate the chat and map page headings.

The official V1 repository is https://github.com/realvjy/3dicons (develop).
`LICENSE` is its complete, unmodified CC0 1.0 Universal text, retrieved from
Git blob `670154e3538863b2d9891fd5483160fbdfc89164`.
`sources.json` records the three actual embedded assets, their official CDN
and repository metadata URLs, original hashes and dimensions. These assets
retain their CC0 dedication independently of the project license.
