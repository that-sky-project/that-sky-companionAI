# Retained Unicorn distribution records

`LICENSE` and `SOURCE-OFFER.txt` are preserved from the earlier portable
client distribution. The source-offer text describes that earlier binary
package and is not evidence that a Unicorn binary is present in this source
checkout. No Unicorn DLL, wheel or installed binding is bundled here; Unicorn
is an external dependency declared in `app/requirements.txt`.

The prior source offer is retained verbatim. This clarification does not
withdraw or narrow any commitment made for the earlier binary distribution.
A new binary distributor must separately retain the applicable license and
provide the corresponding-source arrangement for the binaries it actually
conveys; this historical record alone is not a new binary-release checklist.
