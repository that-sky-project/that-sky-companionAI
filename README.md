# that-sky-companionAI · 小光开源桌面客户端

本仓库为 **1.0.5 / r8（private-preview.8-redemption）客户端源码**，保留本机地形目录 SHA 修复。登录、账号库和长期续期凭据位于独立私有服务；本仓库只包含 HTTPS 客户端适配，不包含私有服务的登录实现。

从 GitHub 下载源码不会得到 EXE 或便携运行时，请先阅读 [源码构建与运行](SOURCE_BUILD.md)。下面步骤面向已组装完整的 Windows 发行目录。

1. 解压完整目录后运行 `XiaoGuang.exe`，不要单独移动 EXE。
2. 打开“左侧第一项 → 小光账号”（完整向导中也有），使用邮箱验证码注册，再登录小光服务。默认服务为 `https://auth.dantarian.top`，不必手工填写服务令牌。新密码为8至30个字符，须含大写字母、小写字母及符号，不强制数字；原有密码仍可登录。
   注册登录后，请联系管理员获取密钥，在“小光账号”页兑换开通或续期。兑换后的期限绑定当前用户编号，已使用密钥不能转给其他账号。
3. 小光服务账号与网易游戏账号分开。网易游戏号继续使用原有邮箱/手机号登录流程。邮箱密码在本机转换为摘要；服务加密托管摘要和续期凭据，自动续期默认开启。
4. 本机地图/资源仍通过原有完整向导从自己的 APK 生成，不随客户端提供游戏资源。

新桌面版默认数据目录为 `%LOCALAPPDATA%\XiaoGuangPrivate\data`，不覆盖旧安装或服务器数据。Windows 需要可用的 Microsoft Edge WebView2 Runtime；缺少时需安装微软的该运行库。

关闭窗口会停止这一客户端启动的后台。开源源码中没有统一服务密钥；服务令牌按用户和客户端独立签发。

**运行后的 data、日志、抓包、服务配置和账号缓存不要提交到开源仓库。** 客户端直连游戏，因此本机运行缓存仍包含必要游戏 session，不能将它当成公开资料。

源码构建见 `tools/build_desktop.ps1`；已有浏览器面板作为高级配置入口保留，EXE 使用同一个本机后台，不另开一套游戏逻辑。

邮箱验证码10分钟有效、只能使用一次，支持邮箱找回服务密码。服务令牌由Windows DPAPI保护；退出服务账号不会删除地形、录图或AI设置。收费校验已接通：管理员可生成一次性密钥，或按用户编号人工管理期限。未开通、到期或暂停时停止运行，续期不删除原有游戏数据。服务器明确指定的管理员测试账号不受期限限制。

未登录时默认显示“小光账号”登录页；“忘记密码”可通过邮箱验证码重置密码。网易账号仍在独立的“游戏账号”页。

密钥的“兑换有效期”是领取期限，兑换后才开始计算使用天数；未到期续期在原到期时间后追加。密钥不是邮箱验证码，也不是旧服务令牌。服务端只保存密钥摘要，后台明文仅生成时显示一次。

## 开发与检查

客户端源码沿用 [LICENSE](LICENSE)、[NOTICE](NOTICE) 和 [第三方声明](THIRD_PARTY_NOTICES)。纯源码不包含游戏 APK、地图网格、个人配置、运行缓存或私有服务端。

离线检查（Python 3.12 与 `app/requirements.txt` 依赖）：

```sh
python -B -m unittest discover -s tests -v
```

测试使用临时目录和伪客户端，禁止连接上游；不启动游戏、不发送邮件、不登录真实账号。

旧版网站的本地注册、SMTP、管理员及 API-key 模块已从本客户端源码移除；小光账号与游戏账号登录均继续通过私有 HTTPS 服务处理。
